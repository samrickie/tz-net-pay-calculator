# Tanzania Net Pay Calculator

A fast, mobile-first, static web app for estimating Tanzania Mainland monthly take-home pay.

## Includes
- Basic salary + taxable allowances
- Resident individual PAYE bands (reviewed Sep/Oct 2026)
- NSSF employee share (10%)
- PSSSF employee share (5%)
- Optional HESLB repayment (15% of basic salary)
- Other deductions
- Monthly and annual take-home pay
- Offline-capable PWA shell

## Free hosting
### GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, then `main` and `/ (root)`.

### Netlify
Connect this repository. No build command is needed.

### Vercel
Import the repository as a static project. No framework or build command is required.

## Notes
The calculator is an estimate and should not replace an employer payroll statement or professional tax advice.
